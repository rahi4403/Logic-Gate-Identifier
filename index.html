System Architecture

End-to-End Inference Pipeline

From behavioral natural language description to gate topology and verified hardware truth table synthesis.

STAGE 01

Input Specification

Raw natural text string ingested through REST endpoint or UI sandbox.

STAGE 02

WordPiece Tokenizer

Subword tokenization with max_length=64 truncation & attention mask padding.

STAGE 03

DistilBERT SLM

6 transformer encoder layers extract bidirectional contextual logic relationships.

STAGE 04

Classifier Head

Linear dense layer + Softmax projects 768-dim [CLS] token to 7 class probabilities.

STAGE 05

Logic & HDL Synthesis

Instantiates truth table, Boolean equation, IC mapping, and synthesizable Verilog.

LogicGate Identifier API Documentation

REST API Contract & Integration Reference

POST /api/classify

Classifies a natural-language circuit behavior into a target logic gate.

curl -X POST "http://localhost:8000/api/classify" \
  -H "Content-Type: application/json" \
  -d '{"description": "output high only when both inputs are high"}'
Sample JSON Response: 
{
  "query": "output high only when both inputs are high",
  "predicted_gate": "AND",
  "confidence": 100.0,
  "probabilities": {
    "AND": 100.0,
    "OR": 0.0,
    "NOT": 0.0,
    "NAND": 0.0,
    "NOR": 0.0,
    "XOR": 0.0,
    "XNOR": 0.0
  },
  "details": {
    "name": "AND Gate",
    "boolean_expression": "Q = A · B",
    "ic_package": "7408 (Quad 2-Input AND Gate)",
    "transistor_count": 6
  }
}
Python Client Integration: 
import requests

res = requests.post("http://localhost:8000/api/classify", json={
    "description": "reverses the incoming signal"
})
gate = res.json()["predicted_gate"]
print("Identified Gate:", gate) # Output: NOT
